# Group Media Encryption Policy

Last updated: 2026-03-08

## Scope

Applies to non-text group and direct chat attachments (`image`, `voice`, `file`).

## Key Versioning Strategy (Current)

- Media messages use envelope format `med1`.
- Envelope fields:
  - `v`: envelope format version (`med1`)
  - `k`: wrapped per-message AES media key
  - `m`: encrypted metadata payload (`mmd1`)
  - `kv`: key version used to wrap the media key
- For direct chats, `kv=1` baseline is used.
- For groups, the client stores current group key version from `api/get_group_key.php` and writes it into `kv` for every encrypted media message.
- On decrypt, if envelope `kv` differs from cached group key version, client refreshes current group key before decrypting.

This provides rotation-ready behavior without breaking message format.

## Rotation Strategy (Operational)

- Rotation should be done at group-key level (shared key) in a controlled window.
- New outgoing media/text uses the new key version.
- Existing messages remain decryptable by preserving historical wrapped keys or by rotating only when old content is purged.

## Legacy/Backfill Policy

Project decision for this phase: old unencrypted messages/files are intentionally removed.

Recommended one-time cleanup sequence in development/staging:

1. Backup DB and uploads directories.
2. Delete legacy rows/files that do not match encrypted envelope expectations.
3. Keep only encrypted media rows generated by current clients.

Example SQL patterns (adjust to environment before running):

```sql
-- Remove legacy non-envelope media rows
DELETE FROM messages
WHERE message_type IN ('image', 'voice', 'file')
  AND (message IS NULL OR message NOT LIKE '{"v":"med1"%');

-- Optional: remove legacy non-group text rows if needed
-- DELETE FROM messages WHERE message_type = 'text' AND group_id IS NOT NULL AND message NOT LIKE 'gcm1:%';
```

After DB cleanup, remove orphaned files under:
- `uploads/images/`
- `uploads/voice_messages/`
- `uploads/files/`

## Future Hardening

- Add admin rotation endpoint and audit trail.
